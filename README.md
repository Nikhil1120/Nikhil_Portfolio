# Nikhil Thipparthi - Portfolio (Vite + React)

A modern, responsive portfolio website built with **Vite + React** showcasing my skills, experience, and projects as a Full Stack Developer.

## 🚀 Features

- **⚡ Lightning Fast**: Built with Vite for instant hot module replacement
- **Modern React Architecture**: Built with functional components and hooks
- **Responsive Design**: Optimized for all device sizes
- **Smooth Animations**: AOS (Animate On Scroll) library integration
- **Interactive Components**: Dynamic contact form and social links
- **Professional Layout**: Clean and modern UI design
- **Performance Optimized**: Fast loading and smooth interactions

## 🛠️ Technologies Used

- **Build Tool**: Vite 7.1.2 (Latest)
- **Frontend**: React.js 19.1.1 (Latest)
- **Styling**: CSS3 with custom animations
- **Animations**: AOS (Animate On Scroll)
- **Icons**: Font Awesome
- **Fonts**: Google Fonts (Poppins)

## 🚀 Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm (comes with Node.js)

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

## 📦 Available Scripts

- `npm run dev` - Starts the development server (Vite)
- `npm run build` - Builds the app for production
- `npm run preview` - Preview the production build locally
- `npm run lint` - Run ESLint for code quality

## 🎨 Sections

1. **Home**: Hero section with introduction and profile image
2. **About**: Detailed information about background and expertise
3. **Skills**: Technical skills organized by categories
4. **Internships**: Work experience timeline
5. **Projects**: Showcase of completed projects
6. **Contact**: Interactive contact form
7. **Resume**: Download link for resume
8. **Connect**: Social media links
9. **Footer**: Copyright information

## 🔧 Customization

### Adding New Sections
1. Create a new component in `src/components/`
2. Import and add it to `App.jsx`
3. Add corresponding styles in `src/styles/App.css`

### Updating Content
- Modify the data arrays in each component
- Update images in the `public/` folder
- Edit text content directly in the component files

### Styling
- All styles are in `src/styles/App.css`
- Uses CSS Grid and Flexbox for responsive layouts
- Custom animations and hover effects included

## 📱 Responsive Design

The portfolio is fully responsive and optimized for:
- Desktop (1024px and above)
- Tablet (768px - 1023px)
- Mobile (up to 767px)

## 🚀 Deployment

### Build for Production
```bash
npm run build
```

### Deploy to Vercel (Recommended)
1. Install Vercel CLI:
```bash
npm install -g vercel
```

2. Deploy:
```bash
vercel
```

### Deploy to Netlify
1. Build the project:
```bash
npm run build
```

2. Upload the `dist` folder to Netlify

## ⚡ Why Vite?

- **Faster Development**: Instant hot module replacement
- **Modern Build Tool**: Uses ES modules for faster builds
- **Better Performance**: Optimized for modern browsers
- **Rich Features**: Built-in TypeScript, CSS modules, and more
- **Active Development**: Continuously updated and improved
